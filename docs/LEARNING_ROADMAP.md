# 面向实习的项目主线

目标：通过可复现的小实验展示结构化网页处理、可复用规则生成、自动评审与反馈迭代能力。

## 下一阶段优先项

1. 对网页按 DOM 结构分组，划分少量开发页与未见验证页。
2. 根据开发页生成每组的 XPath 或解析规则，保存生成输入、版本与运行记录。
3. 用明确的正文质量 Rubrics 审核结果，记录证据与不确定项。
4. 对失败规则生成修改候选；通过已有回归及未见样本验证后再启用。
5. 统计漏提、误提、页面耗时、模型调用及规则复用数量，形成演示与真实项目叙事。

图片 OCR 保留为辅助分支，暂缓继续精修水印及任意图片纠错。现有工程测试不等于真实页面准确率，AI 审核也不自动成为真值。

## 个人学习验收

- 自己写出 lxml XPath 标题和正文提取脚本。
- 能解释正文容器定位、错误样例和训练/验证泄漏。
- 亲自完成一次提出规则、运行、审阅差异、修改、回归的过程。
- 讲清工具调用与模型训练的区别，区分规则迭代、经验复用与强化学习。
- 用真实结果做 3 分钟演示，明确自己的贡献与 AI 协助范围。

近期验收目标是两类模板上的规则复用与可审计反馈闭环；不以处理任意网站作为实习申请前提。
