## 你现在亲手做的操作

在VS Code PowerShell执行以下命令，都在本机运行，不需要GPU，也不调用模型：

~~~powershell
cd "D:\codex project\web_extract_demo"
.\.venv\Scripts\python.exe -X utf8 .\learning\prepare_sft_data.py --check-existing
.\.venv\Scripts\python.exe -X utf8 .\learning\check_sft_references.py
.\.venv\Scripts\python.exe -X utf8 .\training\minimal_sft.py dry-check
~~~

第一条预期为两条历史任务检查通过；第二条六篇REFERENCE PASS；第三条train=1、dev=1，明确gpu_training_tested=false。命令的意义依次是“材料没有被改坏”“可信参考在原始HTML上仍可执行并有证据”“训练入口能读懂这些材料”。它们都不证明模型已经学会任务。

再用VS Code打开output/stage5/unit2/sft_prep/train.jsonl。它只有一条记录，可右键格式化或用Python读取查看。关注messages三个部分：system说明任务边界；user给输出契约和三个同布局DOM摘录；assistant给完整参考extract代码。sources与target记录来源及哈希，不作为模型输入。模型学习的是代码token，不是让它把文章背出来。

训练时prompt对应labels=-100，不计算监督损失；assistant代码与结束标记对应有效labels。模型仍会读取prompt作为上下文。对话前缀必须严格匹配，目标不能为空，超长必须报错，不能把答案尾部截掉继续训练。

## 数据为何只有两条

|分工|布局簇|输入网页|监督目标|
|---|---|---|---|
|train|sina_shell_v2|3篇历史生成页|历史sina_v2.py|
|dev|chinanews_shell_v2|3篇历史生成页|历史chinanews_v2.py|
|独立test|尚无|需要以后冻结新任务/新网页|尚无|

网页数不等于训练任务数：一簇的三篇网页共同组成一个“写抽取器”的任务。重复换顺序、换提示不能变成多个独立任务。train与dev按簇隔离，检测来源哈希、目标AST、prompt和任务组的跨集合重叠；两个目标仍共享许多代码框架，报告保留相似度。没有声称全面消除语义近重复或预训练数据污染。

这些网页/代码已在前面调试过。dev只能帮助观察管线和历史跨簇行为，不是盲测。只用1条train训练即使loss下降也可能只是在记忆代码，不能证明正文质量或泛化提升。正式效果实验需增加多个布局任务、复核目标，并在调试前冻结未见网页/布局；数据预算届时再定。

## 参考代码质量与版本边界

六篇输出通过字段、XPath唯一定位、原文引用、表格行列与顺序检查。新浪正文块43/23/16；中新网7/26/33。后两篇比早期27/34少一条，是独立署名归入作者字段，文字未因这一分类操作丢失。

参考是历史v2教学代码，不是独立金标。历史12页评估有6候选通过、3质量失败、2unknown、1空正文错误，仍可能混入署名变体/互动引导；图像像素没有提取。新规范中原标题元数据与某些新浪图说细化由后处理演示，未合入此历史目标。manifest明确列出限制。这里只允许它作为有限历史SFT管线样例，不能把它标成生产正确代码。

输入是之前选定的文章容器摘录，不包含整页导航。这会简化容器发现任务，不能用本实验宣称模型学会全网页主区定位。保留节点层级、顺序和关键属性；长文本/属性的裁剪有标记和计数，完整原始HTML另存并以哈希校验。压缩输入不是原网页展示副本。

## 最小训练方案

候选模型为Qwen/Qwen2.5-Coder-0.5B-Instruct，优先用较小模型验证流程，尚不承诺代码能力。training/minimal_sft.json记录模型revision、上下文、LoRA和预算；training/README.md说明云端步骤。具体PyTorch/CUDA组合仍需与出租机器镜像匹配，当前依赖文件是待GPU验证方案；下载权重前还应核对该版本模型卡的许可和使用条款。

默认仅1个optimizer step、micro-batch=1、累积=1、LoRA r=8、alpha=16、q_proj/v_proj、学习率1e-4、seed=42。先做tokenizer预检，再冻结相同提示生成before，再train，再用新进程重载adapter生成after。验证非零可训练参数、实际global_step、有限且非零参数差异、保存与重载；不把目录存在当作成功。

输入和输出都不能静默截断；生成达到max_new_tokens只保存为可能截断文本，不能直接执行或判为正确。训练前后比较需固定模型revision、数据哈希、提示和解码参数。loss只验证拟合，不替代Q1—Q5语义审核；质量、轮数和成本必须分开报告。

历史参考检查入口只执行两个已经审阅的固定仓库文件。新模型代码只保存文本，可静态解析，后续执行必须建立真正隔离环境，例如无网络/无宿主挂载的受限容器，限CPU/内存/进程/时间；AST白名单和timeout不等于安全沙箱。本轮不构建或启动执行模型代码的自动闭环。
