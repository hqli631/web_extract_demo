# 有限修复与回滚交付

岗位中的 RSI 不只意味着再调用一次模型。最小工程闭环应把问题、代码版本、候选补丁、回归证据和采用决策连起来；出现退化时必须保留旧版。

本演示复用此前当前对话 Coding Agent 已编写并审核的中新网 v1→v2 补丁。它不是新云端模型自主生成补丁，也不是强化学习。代码运行前锁定两份可信参考源码 SHA256；新生成模型代码不在本机导入。

在项目根目录运行命令：.\.venv\Scripts\python.exe -X utf8 .\learning\run_rsi_delivery.py。依赖路径需要包含 .deps 和项目根目录。

查看 output/stage5/rsi_delivery/index.html。机器可读决策为 report.json，最终活动代码登记为 active_version.json。

流程只有两次有限候选：

1. 在明确标为合成的折叠正文控制中发现 v1 漏掉 inline-only 容器文字。v2 保留文字；3 篇已暴露自然页面、访谈问题、嵌套段落的回归保持不变，因此接受。
2. 构造明确标为破坏性控制的删段候选，删除首段和访谈问题。回归门禁拒绝，活动版本保持 v2，完成拒绝与回滚演示。

学习时关注三个记录：before_gate 告诉你为什么修；candidate_gate 告诉你凭什么采用；active_after 告诉你失败后系统究竟使用哪份代码。少轮数不能补偿正文漏提。

本报告是可复验的工程门禁演示，不是新自然网页准确率。它只使用 3 篇历史已暴露页面和合成控制，未读取新增自然集的封存测试页。图像像素、动态生成内容和其他网站的隐藏导航仍不在已验证范围内。
