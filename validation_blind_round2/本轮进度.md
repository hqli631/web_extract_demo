## 重新运行图片 OCR

在项目目录的 PowerShell 中执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-ocr.txt
.\.venv\Scripts\python.exe ocr_validation_images.py
```

识别读取已下载图片和对应哈希，生成独立的 JSON 和 HTML 报告；重新运行会覆盖这两个 OCR 报告，不修改网页提取结果。
